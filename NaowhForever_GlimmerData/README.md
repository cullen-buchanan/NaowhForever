# Glimmer Data

Where every herb and vein grows, by world map, for QoL's Glimmer (`NaowhForever_QoL/Glimmer/`): its
minimap icons and its Gathered layer on the world map. Generated by `Tools/build/glimmer_nodes.py` from
Wowhead Forever. Load-on-demand, and it needs NaowhForever_QoL: Glimmer loads it once Minimap Icons is
on, so a player who never turns it on never loads it.

## Layout

```
NaowhForever_GlimmerData/
  NaowhForever_GlimmerData.toc   its metadata (LoadOnDemand, needs NaowhForever_QoL), and GlimmerData.xml
  GlimmerData.xml                its one file
  Data/Spots.lua                 ns.GlimmerSpots[uiMapID]: object ID, x and y in tenths of a map percent,
                                 three numbers a spot, one after the other
```

## Why

- A spot is three plain numbers in one flat list per map, not a table each: 25,000 small tables
  would cost far more memory than the numbers they hold.
- Positions are tenths of a map percent, the precision Wowhead gives them.
