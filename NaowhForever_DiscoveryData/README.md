# Discovery Data

The Quest List's quests and rares, generated by `Tools/build/completo_quests.py` and
`Tools/build/completo_rares.py`. Load-on-demand: Discovery loads it the first time the Quest List
reads either list, so a player with the Quest List off never loads it.

## Layout

```
NaowhForever_DiscoveryData/
  NaowhForever_DiscoveryData.toc  its metadata (LoadOnDemand), and DiscoveryData.xml
  DiscoveryData.xml               every file, in load order
  Quests.lua                      every quest of every zone and its chain (ns.CompletoQuestData), generated
  Rares.lua                       every rare of every zone, its spots and drops (ns.CompletoRareData), generated
```

## Why

- The two lists are close to two megabytes once loaded, and the Quest List is off by default.
- Each file fills a table `NaowhForever_Discovery/QuestList/Completo.lua` already made, so the
  Quest List's files keep the table they took as they loaded. Reading any field of either table
  before this addon has loaded loads it.
